# Forge Echo

Local-first soundboard PWA for Battle Forge. It plays ambient tracks and one-shot sounds on a phone or tablet
connected to a speaker, and follows the slides shown on the Battle Forge display.

## Run

```
docker compose up --build -d
```

Open http://localhost:8081. Battle Forge is expected at `http://host.docker.internal:8080`
(override with `BATTLE_FORGE_URL`). Health: `GET /api/health`.

## Coupling with Battle Forge

- Independent repository, own Mongo and media volume.
- Read-only Socket.IO mirror of `dm-library/slides` and `settings/presentation`.
- Data is validated by strict parsers; the live contract test guards against drift:
  `cd server; $env:BATTLE_FORGE_URL='http://localhost:8080'; npm run test:contract`.
- Battle Forge declares `contracts.forgeEcho` (currently 1) in `/api/health`. Forge Echo checks it on every
  connect and shows a warning on the Stage tab when the versions differ.

## Install as an app (PWA)

Open the site in Safari or Chrome and use "Add to Home Screen". The service worker only caches the app shell;
`/api` and audio streams always go to the network. Icons are generated by `python scripts/make-icons.py`
(needs Pillow).

## UI kit

Design tokens live in `src/styles.scss`. Reusable components are in `src/app/ui`: `IntensitySlider`
(large touch slider, used for volume), `ModeToggle` (segmented control, Follow scenes / Hold), `Icon` and
`IconButton` (thin-stroke line icons).

## Development

- Client: `npm ci`, `npm start`, `npm test`.
- Server: `cd server; npm ci; npm test; npm run typecheck`.
